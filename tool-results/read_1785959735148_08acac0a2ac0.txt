     1→     1→// ============================================================
     2→     2→// Madrasha ERP & Accounting Management System (SaaS)
     3→     3→// Database Schema — Prisma (Dual Environment)
     4→     4→// Dev: SQLite  |  Production: PostgreSQL
     5→     5→// Version: 2.0
     6→     6→// ============================================================
     7→     7→// Environment Switch:
     8→     8→//   Dev:  bun run db:dev       (switches to SQLite)
     9→     9→//   Prod: bun run db:prod      (switches to PostgreSQL)
    10→    10→//   The schema types (Decimal, Json) work with BOTH databases
    11→    11→// ============================================================
    12→    12→// Design Principles:
    13→    13→//   - Multi-tenant: tenant_id on every business table
    14→    14→//   - Composite unique constraints prevent cross-tenant data leaks
    15→    15→//   - Soft delete (deleted_at) on transactional entities
    16→    16→//   - Audit fields: created_at, updated_at, created_by, updated_by
    17→    17→//   - Double-entry accounting foundation (chart_of_accounts, journal_entries)
    18→    18→//   - Index strategy optimized for reporting queries
    19→    19→//   - snake_case table names via @@map
    20→    20→//   - Singular table names for consistency
    21→    21→// ============================================================
    22→    22→
    23→    23→generator client {
    24→    24→  provider = "prisma-client-js"
    25→    25→}
    26→    26→
    27→    27→datasource db {
    28→    28→  provider = "sqlite"
    29→    29→  url      = env("DATABASE_URL")
    30→    30→}
