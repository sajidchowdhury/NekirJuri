     1→// ============================================================
     2→// Madrasha ERP & Accounting Management System (SaaS)
     3→// Database Schema — Prisma + SQLite
     4→// Version: 1.0
     5→// ============================================================
     6→// Design Principles:
     7→//   - Multi-tenant: tenant_id on every business table
     8→//   - Composite unique constraints prevent cross-tenant data leaks
     9→//   - Soft delete (deleted_at) on transactional entities
    10→//   - Audit fields: created_at, updated_at, created_by, updated_by
    11→//   - Double-entry accounting foundation (chart_of_accounts, journal_entries)
    12→//   - Index strategy optimized for reporting queries
    13→//   - snake_case table names via @@map
    14→//   - Singular table names for consistency
    15→// ============================================================
    16→
    17→generator client {
    18→  provider = "prisma-client-js"
    19→}
    20→
    21→datasource db {
    22→  provider = "sqlite"
    23→  url      = env("DATABASE_URL")
    24→}
